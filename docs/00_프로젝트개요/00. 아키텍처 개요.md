# 00. 아키텍처 개요

버섯 재배 환경의 센서(온도, 습도, CO2 등)가 MQTT로 데이터를 발행하면, CollectorService가 이를 구독하여 파싱·정제한 뒤 이벤트로 RuleEngine에 전달합니다.
RuleEngine은 전달받은 데이터를 각 재배 환경에 설정된 임계값과 비교하여 정상/이상 여부를 판단하고, 그 결과를 RabbitMQ로 발행합니다.

이때 CollectorService의 검증과 RuleEngine의 판단에 사용되는 재배 환경·센서 정보(임계값 포함)는, 다른 서비스에서 관리되는 원본 데이터를 RabbitMQ 발행 → `@RabbitListener` 구독을 거쳐 우리 쪽 Redis에 동기화해둔 것을 조회하여 사용합니다.

## 구간별 설명

### 1. CollectorService (MQTT 구독 및 파싱·정제)

센서로부터 발행되는 데이터를 MQTT로 구독하고, 수신한 원본 데이터를 파싱·정제하여 이후 처리에 사용할 수 있는 형태로 변환합니다.

- 참고 : [01. CollectorService 구조](./01.%20CollectorService%20구조.md)

### 2. 데이터 전달 (CollectorService → RuleEngine)

CollectorService에서 파싱·정제된 데이터를 `@Async` + `@EventListener` 기반으로 RuleEngine에게 전달합니다.

- 참고 : [02. 데이터 전달(EventListener)](./02.%20데이터%20전달(EventListener).md) 참고.

### 3. RuleEngine (판단)

전달받은 센서 데이터를, 해당 재배 환경에 설정된 임계값과 비교하여 정상 범위인지 이상 상황인지 판단합니다.

- 참고 : [03. RuleEngine 구조](./03.%20RuleEngine.md)

### 4. RuleEngine → RabbitMQ (발행)

RuleEngine의 판단 결과를 RabbitMQ로 발행하여, 이후 이 데이터를 필요로 하는 서비스(알림, 저장 등)가 소비할 수 있도록 합니다.

- 참고 : [04. RabbitMQ 발행](./04.%20RabbitMQ%20발행.md) 참고.

### 5. 재배 환경 및 센서 정보 동기화

CollectorService의 검증과 RuleEngine의 판단에 필요한 재배 환경·센서 정보(임계값 포함)는 다른 서비스에서 관리됩니다. 해당 정보가 등록·수정·삭제될 때마다 RabbitMQ로 발행되며, 이를 `@RabbitListener`로 구독하여 우리 쪽 Redis에 반영해두고 조회 용도로 사용합니다.

- 참고 : [05. 재배 환경 및 센서 정보](./05.%20재배%20환경%20및%20센서%20정보.md) 참고.

## 전체 흐름

```text
[ 다른 서비스 : 재배 환경 및 센서 등록/수정/삭제 ]

        ↓ (AMQP Publish)

[ RabbitMQ ] ──→ [ @RabbitListener 수신 ] ──→ [ Redis 동기화 ]
                                                    ↑
                                                    │ (조회)
                                                    │
[ Sensor (온도, 습도, CO2 등) ]                        │
                                                    │
        ↓ (MQTT Publish)                            │
                                                    │
[ CollectorService ]                                │
    1. MQTT Topic 구독 (Subscribe)                   │
    2. 데이터 파싱 및 정제 (Redis 조회하여 검증) ───────────┘

        ↓ (@Async + @EventListener)
        
[ RuleEngine ]
    1. 센서 데이터 수신
    2. 재배 환경별 임계값 비교 및 규칙(Rule) 검증 (Redis 조회하여 임계값 확인)
    3. 정상/이상 상태 판단
    
        ↓ (AMQP Publish)
        
[ RabbitMQ ]
    1. 판단 결과 메시지 발행
    2. 후속 서비스(알림, 데이터 저장 등)로 전달
```
